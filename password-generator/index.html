Free strong password generator using secure randomness. Passwords are never stored or sent.

Why TaskFlex built this

Strong random passwords made with your browser's secure random generator.

How to use it

  1. Choose the length and character types.
  2. Tap Generate.
  3. Tap Copy.

Questions

Are passwords saved?

Never. They are not stored or sent.

How long should it be?

16 or more is a good start.

Is the password sent anywhere?

No. It is made in your browser with its secure random generator.

How long should a password be?

At least 12 characters. Use 16 or more for important accounts.

Can I remember it?

Random passwords are hard to remember, so use a password manager.

Should I include symbols?

Symbols and mixed case add strength, but length matters most. Some sites reject certain symbols, so untick them if a site does not accept the password.

Is two-step login worth it?

Yes. Turn on two-step verification wherever it is offered.

Who it helps

Anyone who signs up for accounts and wants a unique password for each one instead of reusing a simple one.

Examples

Make a 16 character password with letters, numbers and symbols for your email. Make a longer one for banking and keep it in a password manager.

Tips

Longer is stronger. Never reuse a password and never send it in a message. Save new passwords in a trusted manager straight away.

How it works

The password is built from the character types you tick, using the secure random number generator built into your browser. Nothing is saved and nothing is sent anywhere.

Mistakes to avoid

Using your name, birth year or a keyboard pattern makes a password easy to guess. Avoid using one password for both email and banking, because a single leak would open both.
