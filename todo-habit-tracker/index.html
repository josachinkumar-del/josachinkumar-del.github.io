To-Do and Habits

Free habit tracker and daily to-do list with streaks. Private, no sign-up, stored only on your device.

Why TaskFlex built this

Plan today and build habits with a simple streak count.

How to use it

  1. Add a task and tick it when done.
  2. Add a habit and tap Done today each day.
  3. Watch the streak grow.

Questions

How is a streak counted?

It counts days in a row up to today. If you have not ticked today yet, yesterday still keeps it alive.

Where is it stored?

Only on your device.

Does it need an account?

No. Everything is saved in your browser on this device.

Can I use one list on my phone and my computer?

No. Data is stored per device and browser, so each one keeps its own list.

How do I keep my data safe?

Avoid clearing site data, and write down anything important somewhere else too.

What is the difference between a task and a habit?

A task is done once. A habit repeats and builds a streak.

Can I tick a habit for yesterday?

Habits are meant to be marked each day with Done today.

Who it helps

People who want one simple screen for today's jobs and for habits they are building, such as drinking water, reading or walking.

Examples

Add Pay electricity bill as a task and tick it when it is done. Add Read 10 pages as a habit and tap Done today each evening to grow your streak.

Tips

Keep tasks small and specific. A streak counts days in a row, so choose habits small enough to do every day.

How it works

Tasks and habits are stored in your browser. A task is a one-off job that you tick and clear. A habit has a streak, which counts the days in a row that you tapped Done today.

Mistakes to avoid

Adding too many habits at once is the most common reason streaks break. Start with one or two, and write each task as one clear action such as Call the bank, not a vague goal such as Sort money.
