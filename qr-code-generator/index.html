Questions

Do the codes expire?

No. They are static and are not tracked.

Which error level should I use?

M is fine for most uses. Use H if the code may get scratched or dirty.

Does the code expire?

No. It stores what you entered, so it works as long as that link or detail is still valid.

Is there a watermark?

No.

Should I download PNG or SVG?

PNG for screens and chats, SVG for large prints.

Can I make a Wi-Fi code?

Yes. Choose the Wi-Fi option and enter the network name and password.

Can I change a code later?

No. Make a new one, because the data is stored inside the picture.

Who it helps

Shop owners, event organisers, teachers and anyone who wants people to open a link, join Wi-Fi or call a number by scanning.

Examples

Make a code for your shop's website, a Wi-Fi code for guests, or a phone number for a poster.

Tips

Test the code with your own phone before printing. Leave a quiet white border and print it large enough to scan from a distance. Use SVG for printing because it stays sharp.

How it works

The code is drawn in your browser from the text you type, so the content never goes to a server. A QR code is only a picture of data, so anyone who scans it can read what is inside.

Mistakes to avoid

Do not put private details such as passwords in a code you will show in public. Check a link twice, because a typo makes the code useless once it is printed.
